# projet-systeme-SCADA
Système SCADA miniature basé sur des microcontrôleurs connectés-IST Ouaga 2000-2025-2026
Thème: Étude et implémentation d’un système SCADA(Supervisory Control And Data Acquisition) miniature utilisant des microcontrôleurs connectés
Nom des membres: Zongo P Bénaja ; DEGANAYE GAELLE
Résumé: Conception et réalisation d'un système SCADA IoT industriel basé sur des microcontrôleurs ESP32, intégrant les protocoles MQTT et HTTP pour la supervision en temps réel de variables industrielles. Le système assure la collecte, le stockage et la visualisation des données dans un environnement distribué et sécurisé. Une évaluation comparative des protocoles de communication est menée selon des critères de latence, fiabilité et sécurité.
